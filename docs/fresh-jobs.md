# Fresh Jobs

The fresh jobs page exposes the high-priority instant-response window as a dedicated operator surface.

## What it shows

- jobs marked `fresh`
- job priority
- apply strategy
- source platforms
- manual actions to queue referral drafting or application processing

## Endpoints

- `GET /api/jobs/fresh`

## UI behavior

The `/fresh-jobs` page is where the operator can quickly review watcher-discovered jobs and reinforce the automatic pipeline with manual queue actions when needed.
